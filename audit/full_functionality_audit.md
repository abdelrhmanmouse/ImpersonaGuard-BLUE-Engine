## Component relationships

The name “Domain Similarity” is overloaded in this project and must be disambiguated:

1. `TyposquattingDetector` in `typosquatting_detector.py` is a trusted-brand similarity heuristic with default threshold 0.86 and additional confusable/edit/addition rules.
2. The DGA notebook's Rule-Based method uses `SequenceMatcher` against a separate 15-brand list with threshold 0.72; it is a baseline in a dataset-labeled `dga`/`legit` domain-string experiment. The notebook's ML and Hybrid candidates are separate algorithms.
3. `TyposquattingDomainClassifier` is a distinct learned model using the saved TypoDS TF-IDF/Logistic Regression pipeline and its frozen threshold. It predicts the experiment's dataset label.

No score or prediction from one component is substituted for another. As of the 2026-10-26 update, `BLUE_Engine_AI_Handoff/domain_api.py` exposes DGA and TypoDS predictions on a separate local HTTP service; the Email FastAPI routes remain unchanged. URL feature scoring and brand similarity remain Python interfaces only.

## Overall status

Notebook and artifact follow-up: all three URL notebooks have 21 cells and contain no feature-generation functions or raw URL parsing/acquisition. Notebook training selects numeric columns and replaces infinities with nulls before fitting. The artifact exposes the same ordered 111 feature names as the pipeline, a median `SimpleImputer`, and a 111-input Random Forest. A report notebook explicitly identifies its example URLs as engineered feature rows. These facts do not provide the transformation semantics needed to generate those 111 fields from a URL. Do not invent a substitute; URL raw-input inference remains **BLOCKED**.

Final reruns after the raw-string rejection check: Email API/header **26 passed, 0 failed, 0 skipped**, one deprecation warning; component suite **6 passed**; contract consistency **3 passed**. The first rerun using bare `python` failed during collection because it selected Python 3.11.1 while importing Python 3.12-compiled extensions from the stale Email environment. Re-running with the host Python 3.12.14 executable passed. Exact detail and documented setup limitation are in `audit/implementation_and_test_results.md` and `audit/inference_readiness_report.md`.

Several components have tested local inference paths, but the whole intended product is **not yet ready for reproducible GitHub handoff or production**. Raw URL inference is incomplete; DGA/URL source-data rights and artifact delivery are unresolved; clean dependency installation remains unverified because the offline cache lacked NumPy 2.4.6; and there is no Git repository to inspect. Do not publish model/data files until rights and delivery are approved.
